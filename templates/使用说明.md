# 中文修订 v0.3 使用说明

本补丁由使用者自己的Steam 1.0.14原版文本资源构建。覆盖主翻译表、独立官方战役和官方50日挑战；玩家自制内容文件不修改。

需要Python 3.10+。操作前完全退出游戏。在本目录运行：

```sh
python3 manage_patch.py install
python3 manage_patch.py restore
```

默认定位当前用户的Steam安装。其他目录使用`--game-dir '/实际游戏路径'`。官方50日挑战必须已下载。

安装前校验全部目标与备份，遇到未知资源版本会停止。恢复命令还原本次构建所使用的三份官方原版资源。

排版验证.md和排版截图目录包含v0.3代表性页面检查记录，不代表所有页面和分辨率均已验证。源码和构建步骤见：https://github.com/pai535Huang/they-are-billions-chinese-patch
